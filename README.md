# Polarmed: охотник за слотами — 0.3.2

Адаптация [emias-slot-hunter](https://github.com/polinalamponi/emias-slot-hunter), лицензия MIT, исходное авторство сохранено в `LICENSE`.

Пользовательский скрипт для **https://reg.polarmed.ru/** — портала записи к врачу Мурманской области. Работает через расширение Tampermonkey; это не отдельное расширение из магазина браузера.

Скрипт следит за свободными талонами к любому врачу выбранной специальности либо к одному врачу и пытается записать вас при появлении подходящего времени. Есть фильтры дат/времени, обязательная предварительная проверка, автоматическая запись и режим подтверждения.

**Неофициальный проект, не связанный с Polarmed, Госуслугами или медицинскими организациями.** Сайт может менять API и ограничивать запросы. Результат и наличие записи всегда проверяйте на самом сайте. Гарантии получения талона нет.

**Экспериментальная версия.** Запросы восстановлены по клиентскому коду сайта и предоставленным схемам форм. Автоматические тесты выполняются на искусственных ответах. Реальная запись в аккаунте пользователя при разработке не выполнялась.

## Установка

**[Установить охотника Polarmed](https://raw.githubusercontent.com/Skef14/polarmed-slot-hunter/main/dist/polarmed-slot-hunter.user.js)** — сначала установите Tampermonkey, затем откройте эту ссылку и подтвердите установку. Если менеджер не перехватил ссылку, используйте ручной способ ниже.

1. Установите [Tampermonkey](https://www.tampermonkey.net/): [Chrome / Edge / Яндекс Браузер](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) или [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/).
2. В Chromium-браузерах откройте страницу расширений → Tampermonkey → «Сведения» и включите «Разрешить пользовательские скрипты». Если такого пункта нет, проверьте «Режим разработчика» на странице расширений. После изменения разрешений перезапустите браузер.
3. Откройте **[файл скрипта](dist/polarmed-slot-hunter.user.js)** и нажмите **Raw**. Если Tampermonkey покажет страницу установки — нажмите «Установить». Если открылся обычный текст: Tampermonkey → «Создать новый скрипт» → выделите весь шаблон (Ctrl+A), замените **полным** содержимым файла и сохраните (Ctrl+S).
4. Диагностический скрипт «Polarmed: сбор структуры страницы» для обычного использования **не нужен**. Если он уже установлен, отключите его, чтобы кнопка не мешала.
5. Обновите https://reg.polarmed.ru/ и войдите обычным способом. Устанавливать оригинальный скрипт для ЕМИАС не нужно. Проверьте, что включена только одна копия охотника Polarmed.

Скрипт ЕМИАС устанавливать вместо Polarmed не нужно. Автообновление из исходного репозитория ЕМИАС отключено: его обновление не должно затереть адаптацию.

## Использование

1. На самом сайте откройте свободную запись, выберите поликлинику, пациента и **специальность**. Дождитесь списка врачей. **Конкретного врача выбирать не нужно.**
2. Внизу справа нажмите **«🎯 Охотник: открыть настройки»**. Это большая кликабельная плашка, а не просто уведомление. Если выбор на сайте ещё не готов, откроется окно с инструкцией и кнопкой «Проверить выбор и открыть настройки»; после выбора специальности нажмите её.
3. На первом шаге отметьте **«Любой врач: …»**. Если врач уже выбран на сайте, будет доступна и прежняя цель для поиска только у него. На втором шаге задайте даты, время дня и режим «сразу» или «сначала спрашивать».
4. Если хотите заменить старую запись более ранней, введите её дату и время в специальное поле. Это **только фильтр**, старая запись не изменяется. В режиме «в выбранный день, в любое время» ограничение «раньше старой записи» намеренно не применяется, как в оригинале.
5. Пройдите обязательный холостой прогон, прочтите отчёт и подтвердите условия. Он ничего не бронирует.
6. Запустите поиск и оставьте вкладку открытой, компьютер — включённым. Интервал не меньше 20 секунд, при сетевых ошибках и ограничениях сервера есть паузы.

В режиме «Любой врач» скрипт каждый раз обновляет список врачей специальности и последовательно проверяет их талоны. Выбирается **первый врач по порядку сайта, у которого есть подходящий талон**, а у него — самый ранний подходящий талон (с учётом заданных фильтров). Это не поиск самого раннего времени сразу среди всех врачей. Нулевой счётчик талонов не исключает врача: счётчики могут запаздывать. После находки остальные врачи в этом проходе не опрашиваются. Имя найденного врача видно в холостом прогоне, подтверждении и уведомлении о записи. Перед записью повторно проверяются именно этот врач и талон; если они недоступны, без вашего согласия не подставляется другой врач в уже показанном подтверждении.

После успешной записи скрипт ищет тот же талон, пациента и поликлинику в личном кабинете. Если не удаётся проверить результат, он сообщает именно об этом, а не показывает ложное «Записано».

## Пока идёт поиск: вкладки, работа и игры

Можно переключаться на другие вкладки, работать и играть. Но браузер и вкладка Polarmed должны оставаться открытыми, а компьютер — включённым и без перехода в сон.

- Не выходите из аккаунта и не меняйте пациента, поликлинику или специальность во вкладке с поиском.
- Добавьте `reg.polarmed.ru` в исключения экономии памяти / спящих вкладок браузера. В Chrome: «Настройки» → «Производительность» → сайты, которые всегда остаются активными; в других браузерах название настройки отличается.
- Открытая вкладка не означает гарантированный интервал: браузер может замедлять фоновые задачи, а игра — занимать ресурсы компьютера. Проверки выполняются **не чаще**, чем раз в 20 секунд между проходами, но могут происходить реже. У врача/врачей внутри прохода идут последовательные запросы.
- Не уменьшайте минимальный интервал и не запускайте несколько независимых копий ради ускорения: это создаёт нагрузку на общий медицинский сервис и может привести к ограничению доступа.
- В режиме «сразу» отвечать на каждую находку не нужно. В режиме «сначала спрашивать» нужно ответить в течение **60 секунд**, иначе талон пропускается. Звук и браузерные уведомления зависят от разрешений браузера и ОС, поэтому не полагайтесь только на них.
- При сне компьютера, закрытом браузере, пропавшем интернете или истёкшей сессии поиск не гарантируется. Скрипт не работает в облаке или на выключенном компьютере.

## Старый талон и защита от дублей

**Скрипт никогда ничего не отменяет.** Отдельного механизма переноса на сайте не обнаружено. Используется только создание новой записи; если сайт не разрешает её при существующей, старая остаётся нетронутой.

После новой записи проверьте её в `/profile/`. Только после этого, если нужно, отмените старую вручную. Не отменяйте старый талон заранее ради запуска охотника.

Перед запросом записи сохраняется защитная метка. После любой попытки — успешной, отклонённой или с потерянным ответом — дальнейшие записи для этого пациента и поликлиники блокируются, в том числе после перезагрузки и в другой вкладке. Поиск останавливается. Продолжить можно только после ручной проверки результата: «Настроить заново» → «Я проверил результат предыдущей попытки» → подтвердить снятие блокировки → новый холостой прогон. **Не снимайте блокировку, не проверив личный кабинет.**

Отменить уже отправленный запрос кнопка «Остановить» не может. Если запрос был отправлен до остановки, проверяйте результат на сайте.

## Отличия от ЕМИАС

- Только свободная запись: к любому врачу выбранной специальности либо к конкретному врачу. Направления на анализы и исследования, автоматический выбор других учреждений пока не перенесены.
- Нет автоматической отмены, переноса и непрерывного улучшения уже пойманной записи.
- Нет автоматического учёта других записей, пересечений и дороги. Проверьте их самостоятельно; в интерфейсе эта функция явно отключена.
- Вход через ЕСИА и продление внутренней сессии `n3` не эмулируются. Если сессия закончилась, повторите вход/выбор пациента и специальности на самом сайте.
- При перезагрузке поиск возобновляется после восстановления выбранного пациента и специальности сайтом (для одиночного врача — также врача). Если контекст не восстановился, выберите их заново и нажмите кнопку охотника. Смена пациента, специальности или поликлиники требует новой настройки. В режиме «Любой врач» выбор другого врача внутри той же специальности цель не меняет.
- Для защиты изменяющих запросов между вкладками нужны Web Locks: используйте современный Chrome, Edge или Firefox. Проверки в фоновой вкладке браузер может замедлять.

## Приватность

Нет своего сервера, аналитики, отправки данных в Telegram или сторонних библиотек. Запросы разрешены только к пяти известным адресам reg.polarmed.ru: список врачей, поиск талонов, подтверждение, штатное сохранение записи в кабинете и чтение кабинета.

ФИО, patient_id, history_id и токены сессии берутся из уже загруженной модели сайта только в память. Если JS-модель недоступна менеджеру userscript, используется запасной путь: выбранный в URL `preset` из штатного хранилища Amplify и выбранные элементы страницы. Первый попавшийся пациент из хранилища никогда не выбирается; при устаревших или противоречивых данных работа блокируется. Данные отправляются только самому Polarmed в тех же полях, которые использует его клиент, и не попадают в конфигурацию/журнал охотника. В localStorage хранятся условия, ID врача/поликлиники/талона, время попытки и SHA-256-привязка к пациенту и поликлинике; медицинские интересы и время приёма сами по себе тоже чувствительны. Учитывайте это на общем компьютере.

Материалы `data-site/` не включаются в сборку и добавлены в `.gitignore`.

## Если «Проверить выбор» не открывает настройки

В 0.3.2 исправлена ошибочная обязательность «истории обращения». В свободной записи она может отсутствовать: во все соответствующие формы отправляется пустое поле `history_id`, а не выдуманный идентификатор. Если сайт передал ID истории, он сохраняется в запросах. Проверки пациента, поликлиники, специальности, сессии и CSRF остаются обязательными.

В 0.3.1 кнопка сразу показывает «Проверяю выбор…», затем либо открывает мастер, либо показывает новое сообщение «Проверка №… не пройдена» с причиной. Проверка ограничена 10 секундами. Если этого поведения нет, в Tampermonkey осталась старая версия: замените содержимое существующего скрипта файлом `dist/polarmed-slot-hunter.user.js`, сохраните и перезагрузите сайт. Проверьте, что включена только одна копия охотника.

При ошибке можно прислать **только текст сообщения с кодом `P_…`**: он не содержит ФИО, полиса, идентификаторов или токенов. `P_SELECTION`/`P_LIST` — дождитесь выбора специальности; `P_PATIENT` — повторите шаг пациента; `P_FIELDS` перечисляет названия отсутствующих полей, а не их значения. Не присылайте содержимое localStorage, cookies или полный URL с параметрами пациента.

## Обновление и удаление

Обновление пока **ручное**: остановите поиск, замените весь текст существующего скрипта в Tampermonkey актуальным файлом `dist/polarmed-slot-hunter.user.js`, сохраните и перезагрузите вкладку. Номер версии виден в заголовке скрипта. Не создавайте вторую одновременно включённую копию. После обновления пройдите холостой прогон и проверьте условия заново.

Для удаления остановите поиск и удалите скрипт из Tampermonkey. Сами медицинские записи от этого **не отменяются**. Локальные настройки остаются в данных сайта; при необходимости удаляйте только ключи с префиксом `polarmedSlotHunter:` через инструменты браузера. Не удаляйте защитную метку попытки, пока не проверите результат записи. Очистка всех данных Polarmed может завершить вход и удалить также настройки самого сайта.

## Сообщения об ошибках

Откройте [Issues этого репозитория](https://github.com/Skef14/polarmed-slot-hunter/issues), указав версию охотника, браузер и его версию, последовательность действий и безопасный текст ошибки. Не размещайте медицинские данные, ФИО пациента, дату рождения, полис, СНИЛС, patient_id, историю посещений, cookie, токены, содержимое хранилища, необработанный HAR или ссылки с параметрами пациента. Скриншоты предварительно обрежьте/обезличьте. Не делайте ненужную запись и не отменяйте существующую ради воспроизведения ошибки.

## Разработка

```text
npm test
npm run build:polarmed
npm run build:inspector
```

Для разработки нужен Node.js 18 или новее, внешних npm-зависимостей нет. `npm test` также проверяет отсутствие некоторых типов персональных данных. Это не заменяет ручную проверку перед публикацией.

Исходный проект и его сборка сохранены отдельно. `npm run build` по-прежнему собирает вариант для ЕМИАС, `npm run build:polarmed` — основной файл Polarmed. Технические наблюдения: [docs/polarmed-adaptation.md](docs/polarmed-adaptation.md).
