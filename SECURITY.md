# Приватность и безопасность

Не публикуйте в Issues и Pull Requests данные пациентов, cookie, токены, HAR,
содержимое localStorage/sessionStorage и ссылки с параметрами пациента.
Материалы `data-site/` предназначены только для локального исследования и
не должны включаться в коммиты, архивы релизов и сборки.

При подозрении на ошибку записи остановите охотника и проверьте личный кабинет
Polarmed. Не отменяйте существующую запись ради эксперимента. Не снимайте
блокировку предыдущей попытки, пока не проверите её результат.

Публичное описание потенциальной уязвимости должно быть обезличенным:
не прикладывайте рабочие токены или доступ к аккаунту. Для приватного
сообщения используйте GitHub Private Vulnerability Reporting, если владелец
репозитория включил эту возможность на вкладке Security. Не проверяйте
уязвимости на чужих аккаунтах и не создавайте реальных медицинских записей
ради проверки.
